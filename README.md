# صحتي وسكري

منصة صحتي وسكري لمتابعة مرض السكري وتنظيم المعلومات الصحية اليومية. تطبيق ويب عربي كامل (واجهة عربية `ar-IQ` باتجاه RTL) مع خادم فعلي وقاعدة بيانات PostgreSQL دائمة.

> المنصة أداة لتوثيق ومتابعة المعلومات الصحية الشخصية، **ولا تُغني عن استشارة الطبيب ولا عن خدمات الطوارئ**، ولا تُقدّم تشخيصًا ولا جرعات ولا خطط علاجية.

---

## 1. المزايا المنفَّذة

| المجموعة | التفصيل |
|---|---|
| الحسابات | تسجيل مريض جديد، دخول/خروج، تغيير كلمة المرور؛ تفعيل البريد واستعادة كلمة المرور برمز بريد إلكتروني عند تمكين إعدادات OTP، مع مسار استعادة بإشراف الإدارة |
| الملف الصحي | المجموعات الأربع: (أ) بيانات السكري، (ب) الأمراض والحالات، (ج) المعلومات التناسلية، (د) معلومات إضافية — مع مؤشر اكتمال الملف |
| قياسات السكر | وحدتان `mg/dL` و `mmol/L` مع تحويل دقيق (`mmol/L = mg/dL ÷ 18.0182`)، حفظ القيمة الأصلية + القيمة الموحّدة، تنبيه وتأكيد للقيم غير المعتادة، منع القيم المستحيلة |
| الأدوية | خطة الدواء الموصوفة (`medications`) وسجل الجرعات الفعلي (`administrations`) منفصلان تمامًا؛ لا تُكتب الجرعات السابقة فوق بعضها |
| يومياتي | الوجبات والكربوهيدرات، النشاط البدني، النوم، الأعراض، العوامل اليومية |
| الوزن والتحاليل | سجل وزن تاريخي مع مؤشر كتلة الجسم، ونتائج تحاليل مُدخلة يدويًا (بما فيها HbA1c) |
| التقارير | ملخص لفترات 7/30/90 يومًا أو فترة مخصّصة (حتى سنة)، وملف **PDF عربي** بعنوان «تقرير متابعة مرض السكري» وإخلاء مسؤولية إلزامي |
| لوحة المريض | ملخصات ورسوم بيانية عربية (Recharts) وحالات فراغ واضحة |
| بوابة الإدارة | إدارة حسابات المرضى، وطلبات استعادة كلمة المرور (تحقق يدوي → رمز لمرة واحدة → استبدال كلمة المرور) |
| الأمان | تجزئة bcrypt، جلسات بكوكي HttpOnly/Secure/SameSite، CSRF، تحديد معدل، تشفير الرقم الوطني، سجل تدقيق |

### حدود هذه النسخة (خارج النطاق)
لا يوجد تطبيق طبيب، ولا جلسات QR، ولا حاسبات جرعات أنسولين، ولا تشخيص بالذكاء الاصطناعي، ولا تكامل CGM، ولا رسائل SMS، ولا مدفوعات أو ميزات مستشفيات.

---

## 2. الأدوار

- **PATIENT (المريض)**: يملك بياناته الصحية فقط، ولا يمكنه الوصول إلى بيانات أي مريض آخر.
- **ADMIN (الإدارة)**: يتعرّف على الحسابات (الاسم الكامل، البريد، الرقم الوطني **مقنّعًا**، الهاتف، حالة الحساب) ويعالج طلبات استعادة كلمة المرور — **ولا يملك أي وصول إلى البيانات الطبية**.

---

## 3. التقنيات

Next.js 15 (App Router) + React 19 + TypeScript · PostgreSQL 17 + Drizzle ORM · Tailwind CSS · Recharts · bcryptjs · WeasyPrint (توليد PDF عربي RTL بخطوط مضمّنة).

---

## 4. التشغيل السريع

المتطلبات: Node.js 20+، PostgreSQL 15+، وPython مع اعتماديات `requirements-pdf.txt` ومكتبات Pango/Cairo لتوليد PDF (راجع `Dockerfile`).

```bash
# 1) الاعتماديات
npm install

# 2) إعداد المتغيرات البيئية
cp .env.example .env.local     # ثم عدّل القيم (راجع القسم 5)

# 3) تشغيل PostgreSQL وإنشاء قاعدة البيانات والدور
bash scripts/setup-postgres.sh

# 4) الترحيلات + حساب المدير الأول (من متغيرات البيئة)
npm run db:migrate
npx tsx scripts/create-admin.ts

# 5) البناء والتشغيل
npm run build
npm run start          # http://localhost:3000
```

عند أول تسجيل دخول للمدير: **تُجبر الإدارة على إعداد كلمة المرور عبر رابط الدعوة** قبل الوصول إلى لوحة التحكم.

> إذا كان خادم PostgreSQL متوقفًا بعد إعادة تشغيل البيئة، شغّله بالأمر: `bash scripts/start-postgres.sh`

## 5. متغيرات البيئة (`.env.local`)

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | اتصال PostgreSQL |
| `SESSION_SECRET` | سر توقيع الجلسات (48 بايت عشوائية) |
| `FIELD_ENCRYPTION_KEY` | مفتاح تشفير الحقول الحساسة (32 بايت base64) — لا تغيّره بعد إدخال بيانات |
| `NATIONAL_ID_PEPPER` | سر بناء فهرس البحث عن الرقم الوطني (HMAC) |
| `APP_URL` | عنوان التطبيق |
| `DISPLAY_TIMEZONE` | منطقة العرض الافتراضية (`Asia/Baghdad`) — التخزين دائمًا UTC |
| `INITIAL_ADMIN_EMAIL` | بريد المدير الأول؛ يرسل `scripts/create-admin.ts` رابط إعداد أحادي الاستخدام صالحًا 30 دقيقة |
| `SESSION_IDLE_HOURS` / `SESSION_ABSOLUTE_DAYS` | مهلة الخمول والمهلة المطلقة للجلسة |
| `SAHATI_PDF_RENDERER_PYTHON` | مسار Python الذي يحتوي على WeasyPrint؛ تضبطه صورة Docker تلقائيًا |
| `EMAIL_OTP_ENABLED` / `EMAIL_ACTIVATION_REQUIRED` / `EMAIL_PASSWORD_RECOVERY_ENABLED` | تمكين رموز البريد وتفعيل الحساب والاستعادة؛ معطّلة افتراضيًا وتتطلب إعداد Resend عند تمكينها |
| `RESEND_API_KEY` / `RESEND_FROM_EMAIL` | إعداد خدمة إرسال البريد عند تمكين OTP |

توليد أسرار جديدة:

```bash
openssl rand -base64 48   # SESSION_SECRET
openssl rand -base64 32   # FIELD_ENCRYPTION_KEY
openssl rand -hex 32      # NATIONAL_ID_PEPPER
```

## 6. أوامر npm

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | تشغيل بيئة التطوير على `0.0.0.0:3000` |
| `npm run build` / `npm run start` | بناء الإنتاج وتشغيله |
| `npm run typecheck` | فحص الأنواع (`tsc --noEmit`) |
| `npm run db:migrate` | تطبيق ترحيلات `db/migrations/*.sql` |
| `npm run db:setup` | إعداد PostgreSQL + الترحيلات + إنشاء المدير الأول |
| `npm run db:backup` | نسخة احتياطية مضغوطة من قاعدة البيانات |
| `npm run db:clear-patients` | **حذف كل بيانات المرضى** (مع `--yes`) مع الإبقاء على حسابات الإدارة |

## 7. النسخ الاحتياطي والاستعادة

```bash
npm run db:backup                                  # backups/sahati-<UTC>.dump
pg_restore --clean --if-exists --no-owner -d "$DATABASE_URL" backups/sahati-<UTC>.dump
```

التفاصيل الكاملة لإعداد الإنتاج (HTTPS، خدمة systemd، النسخ الدوري، المراقبة) في [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md).

## 8. الخصوصية والأمان

- كلمات المرور تُخزَّن مجزّأة (bcrypt) فقط، ولا تُطبع في السجلات.
- الرقم الوطني يُخزَّن **مشفَّرًا** (AES-256-GCM) مع آخر 4 أرقام فقط للعرض، ويُستخدم HMAC للبحث الدقيق — ولا يُضمَّن في التقارير أو ملفات PDF إطلاقًا.
- جلسات بكوكي `HttpOnly` + `Secure` (في الإنتاج) + `SameSite=Lax`، مع إبطال الجلسات بعد تغيير كلمة المرور أو استعادتها.
- CSRF على كل طلب كتابة (`x-csrf-token`)، وتحديد معدل على تسجيل الدخول وطلبات الاستعادة ومحاولات إدخال الرمز.
- التفويض يُطبَّق دائمًا على الخادم (صفحات + مسارات API)؛ لا يكفي إخفاء عناصر الواجهة.
- رمز الاستعادة: أرقام عشوائية تشفيريًا، يُخزَّن مجزّأً (SHA-256)، صالح 15 دقيقة، لمرة واحدة، وبحد محاولات.
- سجل تدقيق (`audit_logs`) لكل عملية حساسة.
- **لا تُضاف أي بيانات مرضى وهميين**: المنصة تُسلَّم بقاعدة بيانات نظيفة، وأي بيانات تجريبية تُزال بـ `npm run db:clear-patients -- --yes`.

## 9. البنية العامة

```
src/app/            صفحات الواجهة العربية (عامة + (patient) + admin) ومسارات API
src/server/         المصادقة، الصلاحيات، الخدمات، التحقق، توليد PDF، الاتصال بقاعدة البيانات
src/components/     مكوّنات الواجهة المشتركة (الهيكل، الرسوم البيانية، عناصر التنسيق)
src/lib/            التنسيق العربي للأرقام والتواريخ، التحويلات، رسائل السلامة
db/migrations/      ترحيلات SQL (المصدر المرجعي للمخطط)
scripts/            إعداد PostgreSQL، الترحيل، إنشاء المدير، النسخ الاحتياطي، تنظيف البيانات
docs/               توثيق النشر
```

## 10. الاختبارات

تتوفر اختبارات الأمان عبر `npm run test:security` واختبارات المتصفح عبر `npm run test:browser`. تتطلب اختبارات قاعدة البيانات والمتصفح `SECURITY_TEST_DATABASE_URL` لقاعدة PostgreSQL محلية معزولة؛ تُتخطّى عند عدم ضبطها. لا تستخدم قاعدة الإنتاج للاختبارات.
